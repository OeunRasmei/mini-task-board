# Mini Task Board

A tiny HTML/CSS/JavaScript task app created to practice a real GitHub workflow:

- Issues
- Feature branches
- Pull requests
- Code review
- Co-authored commits
- GitHub Discussions

## Current features

- Add tasks
- Mark tasks complete
- Delete tasks
- Filter all/active/completed tasks
- Clear completed tasks
- Responsive layout

## Suggested roadmap

These are intentionally left for future pull requests:

- Persist tasks with localStorage
- Dark mode
- Edit task names
- Due dates
- Empty-state message
- Keyboard shortcuts
- Accessibility improvements

## Run locally

Open `index.html` in a web browser.

No build tools or dependencies are required.
